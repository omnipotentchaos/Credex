## Methodology

1. **Primary sources**: Official pricing pages, visited 2026-05-10
2. **Cross-validation**: Confirmed via web search for ChatGPT (blocked by 403)
3. **API prices**: Approximate per-token rates from official documentation
4. **Custom plans**: Marked as `-1` in code; not included in savings calculations
5. **Updates**: Tool prices change frequently; all data snapshotted at date above
